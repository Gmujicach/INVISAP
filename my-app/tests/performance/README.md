# Rendimiento

La herramienta prevista para pruebas de carga en Python es Locust; no es un
plugin de pytest. Esta carpeta está reservada para escenarios Locust cuando
se definan rutas, concurrencia y límites de rendimiento esperados.

No hay escenarios de carga implementados todavía. Por ello, no se debe
interpretar una ejecución exitosa de pytest como una prueba de rendimiento.
